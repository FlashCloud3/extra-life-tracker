# Audio Alerts Folder (`/sounds`)

Drop your custom audio files here so they appear automatically in the stream dashboard under **Audio Alerts** -> **Add from App Folder**.

## Supported Audio Formats
- `.mp3`
- `.wav`
- `.ogg`

## Included Default Sounds
- `alert.wav` - Clean double-tone digital notification ping
- `bell.wav` - Crisp bell ding with rich harmonic decay
- `chime.wav` - Gentle melodic two-tone chime
- `coin.wav` - Classic 8-bit retro arcade coin blip
- `fanfare.wav` - Triumphant 4-note milestone celebration fanfare

## How to Use
1. Copy or drop any audio file into this `sounds/` directory.
2. In the Extra Life stream overlay dashboard, navigate to **Settings** -> **Audio Alerts**.
3. Select your sound from the **Add from App Folder** dropdown menu.
4. Click **Preview** to listen to it, then click **Add** to add it to your custom alert sounds.
5. Assign your sound as the default donation sound or milestone sound!
